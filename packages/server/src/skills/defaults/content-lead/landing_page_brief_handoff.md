name: landing_page_brief_handoff
description: Structures a brief for the copywriter before delegating a landing_page deliverable. Defines page sections, tone, USP placement, and CTA.
---

Amikor briefeled a copywritert egy ügyfél landing oldalhoz:

1. **Oldal struktúra** — add meg a következő szekciók tartalmát:
   - Hero: H1 (ügyfélspecifikus állítás — az ICP fájdalompontjaiból, client_profile.md → icp) + almondás + CTA gomb
   - Probléma szekció: 3 konkrét fájdalompont (client_profile.md → icp)
   - Megoldás szekció: az ügyfél terméke hogyan oldja meg ezeket (client_profile.md → usp) — konkrét funkció kiemelések
   - Social bizonyíték: 2-3 ügyfélidézet placeholder ([IDÉZET SZÜKSÉGES])
   - Záró CTA

2. **Hangnem**: Közvetlen és konkrét. Semmi "forradalmasítsd a munkafolyamatodat". Minden mondatnak indokoltnak kell lennie.

3. **SEO kulcsszó**: Ha a delegálásodban szerepel kulcsszó, add meg a copywriternek. Ha nincs, **ne kérdezd meg az embert** (`request_input` tilos) — hívd meg a `submit_to_director` toolt: "Landing page kulcsszó hiányzik. Kérem delegálja az insights-leadnek a kulcsszókutatást, majd küldje vissza a briefet a kulcsszóval."

4. **USP**: Használd a client_profile.md → usp értéket — természetes kontextusban, ne reklámként.

Ezt a briefinget add át a copywriternek a `delegate_to_specialist` segítségével.
