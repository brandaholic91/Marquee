## Összefoglalás

Hat elmaradt funkció implementálása, két logikai csoportban:

**A — Backend plumbing**
1. Memory proposal approval — a patch alkalmazás hiányzott (v0.1 törött workflow)
2. Telemetry wiring — a `turns` tábla soha nem töltődött fel (v0.2 infrastruktúra)
3. Budget guard — `checkBudget()` nem volt bedrótolva az agent futtatásba (v0.2)
4. Default memory templates — startup-kori fájl seed (v0.1)

**B — Dashboard widgetek**
5. Usage widget — tokenhasználat napi összesítő + agentenkénti bontás (v0.2 "Budget widget")
6. Quality trend sparkline — eval score-ok 30 napos trendje (v0.2)

## A. Backend plumbing

### A1. Memory proposal approval

**Érintett fájl:** `packages/server/src/server/routes/memory.ts`

A `POST /api/memory-proposals/:id/approve` route jelenleg csak státuszt frissít és eventet emittál, de a patchet soha nem alkalmazza.

**Megvalósítás — az `"approved"` ágban, a státusz-update előtt:**

1. Proposal betöltése DB-ből: `file` + `patch` mező
2. `simpleGit(opts.dataDir).raw(["apply", "--check"])` a patch tartalmával  
   — ha hibázik: HTTP 409, **nincs státusz-update**
3. Ha ok: `git.raw(["apply"])` + `git.commit("memory: apply agent proposal for <file>")`
4. Státusz frissítés `"approved"`-ra
5. `broker.emit("memory_updated", { file, by: "agent" })`

**Elutasítás esetén** (`"rejected"`): nincs git művelet, csak státusz frissítés.

**Hibakezelés:**
- `git apply --check` fail → 409 `{ error: "patch_conflict", detail: "..." }`
- git commit fail → 500, státusz visszaáll `"pending"`-re
- Proposal nem található → 404

### A2. Telemetry wiring

**Érintett fájlok:**
- `packages/server/src/index.ts` — Telemetry példányosítás
- `packages/server/src/broker/router.ts` — recordTurn hívások

**Telemetry példányosítás (`index.ts`):**

```typescript
const dailyBudgetCents = Number(process.env.MARQUEE_DAILY_BUDGET_CENTS ?? 0);
const telemetry = dailyBudgetCents > 0
  ? new Telemetry(db, { dailyBudgetCents })
  : new Telemetry(db, { dailyBudgetCents: 0 }); // always instantiate, guard disabled
```

A `Telemetry` minden esetben példányosodik (turns mindig íródnak), a guard csak `dailyBudgetCents > 0` esetén aktív.

`AgentRouter` konstruktorába kerül a `telemetry` paraméter.

**Turn rögzítés a routerben:**

A router három helyen kezel `turn_end` eventet (chat agent subscribe, `promptWarmAgent`, `spawnAndPrompt`). Mindhárom helyen:

```typescript
let turnStartedAt = Date.now();
// turn_start handler:
if (e.type === "turn_start") { turnStartedAt = Date.now(); return; }
// turn_end handler (már létező ágba):
if (e.type === "turn_end") {
  const msg = e.message as AssistantMessage;
  if (msg.usage) {
    this.telemetry.recordTurn({
      sessionId,           // az adott agent session ID-ja
      model: msg.model,
      promptTokens: msg.usage.input,
      completionTokens: msg.usage.output,
      costUsdCents: Math.round(msg.usage.cost.total * 100),
      latencyMs: Date.now() - turnStartedAt,
    });
  }
}
```

A `sessionId` mindhárom útvonalban már ismert:
- Chat agent: a `chatAgents` map-ből, session az `agent_sessions` táblából
- Warm agent: `this.warmSessions` map (jelenlegi vagy új session ID)
- Transient specialist: a `spawnAndPrompt`-ban létrehozott session ID

**`AssistantMessage` típusimport:**
```typescript
import type { AssistantMessage } from "@mariozechner/pi-ai";
```

### A3. Budget guard

**Érintett fájl:** `packages/server/src/broker/router.ts`

`MARQUEE_DAILY_BUDGET_CENTS` env var — 0 vagy hiányzik → guard inaktív.

**Soft limit (80%):** a `recordTurn()` után közvetlenül, ha `dailyBudgetCents > 0`:

```typescript
const { totalCents } = this.telemetry.getTodayUsage();
const pct = totalCents / this.telemetry.opts.dailyBudgetCents;
if (pct >= 0.8 && pct < 1.0) {
  this.broker.emit("budget_warning", { usedCents: totalCents, limitCents: ..., pct });
}
```

A `budget_warning` event a Live Feed-en jelenik meg (az SSE már továbbítja az összes broker eventet).

**Hard limit (100%):** `promptWarmAgent()` és `spawnAndPrompt()` elején, **Director kizárásával:**

```typescript
if (role !== "director" && this.telemetry.opts.dailyBudgetCents > 0) {
  try {
    this.telemetry.checkBudget();
  } catch {
    this.broker.emit("budget_exceeded", { role });
    return; // nem fut le a prompt
  }
}
```

A Director mindig futhat (emberi interakció szükséges a blokkolás feloldásához).

## B. Dashboard widgetek

### B1. Új API végpontok

**`GET /api/stats/usage`** — `packages/server/src/server/routes/stats.ts` (új fájl)

```typescript
// SQL: turns JOIN agent_sessions GROUP BY agent_slug, WHERE date(startedAt) = today
// Returns:
{
  today: {
    tokens: number,           // sum(promptTokens + completionTokens)
    costUsdCents: number,     // sum(costUsd) — 0 subscription módban
    byAgent: [
      { agentSlug: string, tokens: number, costUsdCents: number }
    ]                         // csökkenő token sorrend, max 8 agent
  },
  budgetCents: number,        // MARQUEE_DAILY_BUDGET_CENTS env var értéke (0 ha nincs)
  budgetUsedPct: number       // 0–100, 0 ha budgetCents === 0
}
```

**`GET /api/stats/quality`** — ugyanabban a fájlban

```typescript
// SQL: evals JOIN deliverable_revisions GROUP BY date(evals.createdAt), last 30 days
// Returns:
{
  days: [
    {
      date: string,           // "YYYY-MM-DD"
      brand_voice: number,    // avg 1–5
      factual_accuracy: number,
      usp_usage: number,
      count: number           // eval-ok száma ezen a napon
    }
  ],                          // max 30 elem, növekvő dátum sorrend
  avg: {
    brand_voice: number,
    factual_accuracy: number,
    usp_usage: number
  }
}
```

Üres esetén: `days: [], avg: { brand_voice: 0, factual_accuracy: 0, usp_usage: 0 }`.

Mindkét endpoint regisztrálva a `buildServer()`-ben: `registerStatsRoutes(app, opts)`.

### B3. QualityWidget komponens

**Érintett fájl:** `packages/web/src/views/home.tsx`

**QualityWidget tartalma:**

```
Quality              last 30 days
─────────────────────────────────
brand voice    4.2  ▁▂▃▄▅▄▅▆▅▇
factual acc.   3.9  ▃▃▄▃▄▅▄▄▅▄
usp usage      3.8  ▂▃▃▄▃▄▄▃▅▄
```

- Sparkline: inline SVG, 120×16px, nem kell chart library
- Sparkline normalizálás: 1–5 skála → 0–100% magasság, polyline elemekkel
- Átlagszám a sor elején (1 tizedesjegy)
- Dimenzió sor: `brand_voice` → amber, `factual_accuracy` → teal, `usp_usage` → indigo (a meglévő CSS változókhoz illeszkedve)
- Ha nincs eval adat: `"No evals yet"` placeholder
- Frissítés: `api.stats.quality()` egyszer mountkor, nem real-time (eval ritkán változik)
